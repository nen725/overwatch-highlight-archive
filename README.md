# 守望高光档案

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

面向 Windows 的非官方守望先锋高光视频管理器。自动收录游戏已保存的精彩集锦，补充英雄、对局模式、时间和备注，并生成便于分享的压缩副本。

![应用图标](assets/app-icon.png)

## 下载与安装

前往 **[最新版本 Releases](https://github.com/nen725/overwatch-highlight-archive/releases/latest)** 下载：

| 文件 | 用途 |
| --- | --- |
| `OverwatchHighlightArchive-Setup-1.2.0-x64.exe` | 推荐。安装向导，可选安装目录，创建桌面和开始菜单快捷方式，支持卸载。 |
| `OverwatchHighlightArchive-Portable-1.2.0-x64.exe` | 便携版，直接运行，无需安装。 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值。 |

支持 Windows 10/11 64 位；Node.js、FFmpeg 无需单独安装。安装向导提供简体中文、英语、日语和韩语。应用没有代码签名；下载来源和校验值可在本仓库 Release 中核对。

安装到当前用户目录，无需管理员权限。升级前先退出旧版；安装版和便携版使用同一档案目录。旧快捷方式仍指向旧文件时，请从新版重新创建；任务栏固定项也需重新固定。

## 主要功能

- 自动发现默认精彩集锦目录，并支持添加多个自定义目录；每 12 秒递归检查新视频。
- 提取缩略图、时长、分辨率、编码、大小和文件创建时间。
- 视频播放；编辑英雄、模式、时间、标题、备注；收藏、搜索和筛选。
- 在设置中更新英雄名称、职责与头像；内置四语英雄名称缓存。
- 批量生成 H.264/AAC MP4 分享副本，提供最高 720p 和 1080p 两档，支持进度和取消。
- 中、英、日、韩界面；首次启动匹配 Windows 首选系统语言，不支持的语言回退到英语。手动选择立即生效，重启后保留。
- 启动器、程序、快捷方式默认图标和窗口使用统一图标。

## 使用说明

1. **先导出视频。** 在守望先锋游戏中，将精彩表现保存为视频。本工具不读取游戏内部回放代码，也不自动录制游戏。
2. **添加目录。** 首次启动会尝试读取 Windows 文档目录下的 `Overwatch\videos\overwatch` 及游戏配置中的 `VideoPath`。没有找到时，点击「添加视频目录」选择实际保存位置。
3. **查看与整理。** 点击视频查看或编辑信息。英雄、模式仅从文件名辅助匹配，不进行画面 AI 识别。文件创建时间不一定等于对局时间，可手动修改。
4. **添加备注和收藏。** 在详情窗口填写备注并保存；内容显示在视频卡片下方。用户填写的标题和备注不会随界面语言改变。
5. **压缩分享。** 勾选一个或多个视频，选择「轻量分享 · 720p」或「画质优先 · 1080p」，点击压缩并选择输出目录。每次生成独立文件，保留源视频。
6. **设置语言与英雄资料。** 在「设置」中选择语言，或点击「更新英雄资料」。英雄更新需要联网；失败时继续使用缓存。

## 数据保存与限制

- 档案和偏好：`%APPDATA%\overwatch-highlights-manager\library.json`；缩略图位于相邻的 `thumbnails` 文件夹。备份整个目录可保留备注、收藏和语言设置。
- 原视频保留在原目录，应用不上传视频和备注。联网请求用于英雄资料与头像。
- 支持 MP4、WebM、MKV、AVI、MOV；部分内部编码不能直接播放，可用系统播放器打开或生成 H.264 副本。
- 压缩不放大原视频，输出体积取决于源编码与画面，无法保证总会更小。
- 关闭应用会停止当前压缩，队列不跨重启保存；异常退出后可能留下不完整副本。
- 视频身份按绝对路径确定。移动或重命名文件后，旧记录显示离线，新路径重新收录；不会自动合并旧备注。
- 移除监测目录或卸载应用不会删除源视频。安装版默认保留应用档案；需要彻底清除时，请在备份后自行处理上述档案目录。
- 英雄更新取决于资料源的收录时间，不保证与游戏版本发布同步。

## 开发

建议使用 Node.js 22.12 或更高版本，在 Windows 下运行：

```powershell
npm ci
npm run check
npm start
npm run pack
```

安装包和便携版生成在 `release/`。源代码不包含个人档案、原视频、依赖目录或发布二进制。`i18n.js` 管理界面翻译，`assets/hero-names.json` 提供离线英雄名称。
