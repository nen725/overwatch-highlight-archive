# 오버워치 하이라이트 아카이브

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

게임에서 저장한 오버워치 하이라이트 영상을 정리하는 비공식 Windows 도구입니다. 영웅, 모드, 시간, 메모, 즐겨찾기로 최고의 플레이를 관리하고 공유용 압축 사본을 만들 수 있습니다.

![앱 아이콘](assets/app-icon.png)

## 다운로드 및 설치

**[최신 GitHub Release](https://github.com/nen725/overwatch-highlight-archive/releases/latest)** 에서 다음 파일을 선택하세요.

| 파일 | 용도 |
| --- | --- |
| `OverwatchHighlightArchive-Setup-1.2.0-x64.exe` | 권장 설치 파일. 설치 위치 선택, 바탕 화면 및 시작 메뉴 바로 가기 생성, Windows에서 제거를 지원합니다. |
| `OverwatchHighlightArchive-Portable-1.2.0-x64.exe` | 설치 없이 바로 실행하는 포터블 버전입니다. |
| `SHA256SUMS.txt` | 다운로드 파일의 SHA-256 체크섬입니다. |

64비트 Windows 10/11을 지원합니다. Node.js와 FFmpeg는 별도로 설치할 필요가 없습니다. 설치 프로그램은 중국어 간체, 영어, 일본어, 한국어를 지원합니다. 앱은 코드 서명이 되어 있지 않으며 Release 페이지에서 다운로드 출처와 체크섬을 확인할 수 있습니다.

관리자 권한 없이 현재 사용자용으로 설치합니다. 업데이트 전에 이전 버전을 종료하세요. 설치 버전과 포터블 버전은 동일한 아카이브 데이터를 사용합니다. 이전 실행 파일을 가리키는 바로 가기는 다시 만들고, 작업 표시줄의 이전 고정 항목도 해제한 뒤 새 버전을 고정하세요.

## 주요 기능

- 기본 하이라이트 폴더 자동 감지 및 여러 사용자 지정 폴더 등록. 12초마다 하위 폴더까지 확인합니다.
- 미리보기, 재생 길이, 해상도, 코덱, 파일 크기, 생성 시간을 읽습니다.
- 영상 재생, 제목·영웅·모드·시간·메모 편집, 즐겨찾기, 검색 및 필터를 제공합니다.
- 설정에서 영웅 이름, 역할, 초상화를 업데이트합니다. 네 언어의 영웅 이름이 기본 포함됩니다.
- 최대 720p 또는 1080p의 H.264/AAC MP4 사본을 일괄 생성합니다. 진행률 표시와 취소를 지원합니다.
- 중국어, 영어, 일본어, 한국어 UI를 제공합니다. 처음 실행할 때 Windows 기본 언어를 사용하고, 지원하지 않는 언어는 영어로 표시합니다. 수동 변경은 즉시 적용되며 다시 실행해도 유지됩니다.
- 포터블 실행 파일, 프로그램, 기본 바로 가기 및 창에 동일한 아이콘을 사용합니다.

## 사용 방법

1. **먼저 영상을 저장하세요.** 오버워치에서 하이라이트를 영상 파일로 저장하세요. 이 앱은 게임 내 리플레이 코드를 읽거나 게임 플레이를 자동 녹화하지 않습니다.
2. **폴더를 추가하세요.** 처음 실행할 때 Windows 문서 폴더의 `Overwatch\videos\overwatch`와 게임 설정의 `VideoPath`를 확인합니다. 찾지 못하면 **영상 폴더 추가**에서 실제 저장 위치를 선택하세요.
3. **영상을 확인하고 정리하세요.** 카드를 열면 영상을 재생하거나 정보를 편집할 수 있습니다. 영웅과 모드는 파일명에서 추정하며 영상 AI 인식은 사용하지 않습니다. 파일 생성 시간이 경기 시간과 다르면 직접 수정할 수 있습니다.
4. **메모와 즐겨찾기를 저장하세요.** 정보 창에서 메모를 입력하고 저장하면 영상 카드 아래에 표시됩니다. 직접 작성한 제목과 메모는 UI 언어를 변경해도 번역되지 않습니다.
5. **공유용 사본을 만드세요.** 영상을 선택하고 **가벼운 공유 · 720p** 또는 **고화질 · 1080p**를 선택한 다음 저장 폴더를 지정하세요. 고유한 파일명으로 별도 사본을 만들며 원본은 변경하지 않습니다.
6. **언어와 영웅 정보를 설정하세요.** **설정**에서 표시 언어를 선택하거나 **영웅 정보 업데이트**를 누르세요. 업데이트에는 인터넷 연결이 필요하며, 실패하면 저장된 정보를 계속 사용합니다.

## 저장 위치 및 제한 사항

- 아카이브와 설정은 `%APPDATA%\overwatch-highlights-manager\library.json`, 미리보기는 같은 위치의 `thumbnails` 폴더에 저장됩니다. 메모, 즐겨찾기, 언어 설정을 보관하려면 폴더 전체를 백업하세요.
- 원본 영상은 기존 위치에 보관됩니다. 영상이나 메모를 업로드하지 않습니다. 네트워크는 영웅 정보와 초상화를 가져올 때 사용됩니다.
- MP4, WebM, MKV, AVI, MOV를 지원합니다. 일부 코덱은 앱에서 재생할 수 없으므로 시스템 플레이어를 사용하거나 H.264 사본을 만드세요.
- 원본보다 해상도를 높이지 않습니다. 압축 결과는 원본 코덱과 영상에 따라 달라지며 항상 용량이 줄어들지는 않습니다.
- 앱을 닫으면 압축이 중단됩니다. 다시 실행해도 작업 대기열은 복원되지 않으며 중단된 사본이 남을 수 있습니다.
- 영상은 절대 경로로 구분합니다. 이동하거나 이름을 바꾸면 이전 항목은 오프라인으로 표시되고 새 항목으로 추가됩니다. 메모는 자동으로 합쳐지지 않습니다.
- 폴더 검색을 해제하거나 앱을 제거해도 원본 영상은 삭제되지 않습니다. 설치 버전은 기본적으로 아카이브를 유지합니다. 데이터를 직접 삭제하려면 먼저 백업하세요.
- 영웅 정보는 제공 소스의 업데이트 상황에 따라 게임 버전보다 늦게 반영될 수 있습니다.

## 개발

Windows에서 Node.js 22.12 이상을 사용하세요.

```powershell
npm ci
npm run check
npm start
npm run pack
```

설치 파일과 포터블 버전은 `release/`에 생성됩니다. 개인 아카이브, 영상, 의존성 폴더, 배포 실행 파일은 저장소에 포함하지 않습니다. UI 번역은 `i18n.js`, 오프라인 영웅 이름은 `assets/hero-names.json`에 있습니다.
