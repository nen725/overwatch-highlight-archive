# オーバーウォッチ ハイライトアーカイブ

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

ゲームから保存したハイライト動画を整理する、Windows向けの非公式ツールです。ヒーロー、モード、日時、メモ、お気に入りで最高のプレイを管理し、共有用の圧縮コピーを作成できます。

![アプリアイコン](assets/app-icon.png)

## ダウンロードとインストール

**[最新のGitHub Release](https://github.com/nen725/overwatch-highlight-archive/releases/latest)** からダウンロードしてください。

| ファイル | 用途 |
| --- | --- |
| `OverwatchHighlightArchive-Setup-1.2.0-x64.exe` | 推奨インストーラー。保存先の選択、デスクトップとスタートメニューへのショートカット作成、アンインストールに対応。 |
| `OverwatchHighlightArchive-Portable-1.2.0-x64.exe` | インストール不要で直接実行するポータブル版。 |
| `SHA256SUMS.txt` | ダウンロードファイルのSHA-256チェックサム。 |

Windows 10/11の64ビット版に対応。Node.jsやFFmpegの個別インストールは不要です。インストーラーは簡体字中国語、英語、日本語、韓国語に対応します。アプリにコード署名はありません。配布元とチェックサムをReleaseページで確認できます。

管理者権限を使わず、現在のユーザー用にインストールします。更新前に旧版を終了してください。インストール版とポータブル版は同じアーカイブデータを使用します。旧版を指すショートカットは作り直し、タスクバーの古い固定項目は固定を解除して新版を固定してください。

## 主な機能

- 標準のハイライトフォルダーを検出。複数の任意フォルダーも登録でき、12秒ごとにサブフォルダーまで確認します。
- サムネイル、再生時間、解像度、コーデック、容量、ファイル作成日時を取得。
- 動画再生、タイトル・ヒーロー・モード・日時・メモの編集、お気に入り、検索、フィルター。
- 設定画面からヒーロー名、ロール、画像を更新。4言語のヒーロー名を内蔵。
- 最大720pまたは1080pのH.264/AAC MP4コピーを一括作成。進捗表示とキャンセルに対応。
- 中国語、英語、日本語、韓国語のUI。初回起動時はWindowsの優先言語を使用し、未対応の言語は英語になります。手動変更はすぐに反映され、再起動後も保持されます。
- 起動用EXE、実行プログラム、標準ショートカット、ウィンドウのアイコンを統一。

## 使い方

1. **先に動画を保存します。** オーバーウォッチ内でハイライトを動画として保存してください。このアプリはゲーム内リプレイコードを読み取ったり、プレイを自動録画したりしません。
2. **フォルダーを追加します。** 初回起動時にWindowsのドキュメント内の `Overwatch\videos\overwatch` と、ゲーム設定の `VideoPath` を確認します。見つからない場合は「動画フォルダーを追加」から実際の保存先を選んでください。
3. **動画を確認・整理します。** カードを開くと再生と詳細編集ができます。ヒーローとモードはファイル名から推定するもので、映像AI認識ではありません。ファイル作成日時と対戦日時が異なる場合は修正してください。
4. **メモとお気に入りを保存します。** 詳細画面でメモを入力して保存すると、カードの下に表示されます。自分で入力したタイトルとメモは、UI言語を変更しても翻訳されません。
5. **共有用コピーを作成します。** 動画を選び、「軽量共有 · 720p」または「高画質 · 1080p」を選択して出力先を指定します。コピーには固有のファイル名が付き、元動画は変更されません。
6. **言語とヒーローデータを設定します。** 「設定」で表示言語を選ぶか、「ヒーローデータを更新」を実行します。更新にはインターネット接続が必要です。失敗した場合は保存済みデータを使用します。

## 保存場所と制限

- アーカイブと設定は `%APPDATA%\overwatch-highlights-manager\library.json`、サムネイルは同じ場所の `thumbnails` に保存されます。メモ、お気に入り、言語設定の保護にはフォルダー全体をバックアップしてください。
- 元動画は元の場所に残ります。動画やメモをアップロードしません。通信はヒーローデータと画像の取得に使用します。
- MP4、WebM、MKV、AVI、MOVに対応。一部のコーデックはアプリ内で再生できないため、システムのプレイヤーかH.264コピーを使用してください。
- 元動画の解像度を拡大しません。圧縮後の容量は映像と元の形式に依存し、小さくならない場合もあります。
- アプリを閉じると圧縮は停止します。キューは再起動後に復元されず、中断時に不完全なコピーが残る場合があります。
- 動画は絶対パスで識別します。移動や改名をすると旧項目はオフラインになり、新しい項目として登録されます。メモの自動統合はありません。
- フォルダーの監視解除やアンインストールで元動画は削除されません。インストール版は標準でアーカイブを保持します。データを手動削除する場合は、先にバックアップしてください。
- ヒーロー情報は提供元の更新状況に依存し、ゲームの更新より遅れる場合があります。

## 開発

WindowsでNode.js 22.12以降を使用してください。

```powershell
npm ci
npm run check
npm start
npm run pack
```

インストール版とポータブル版は `release/` に生成されます。個人のアーカイブ、動画、依存パッケージ、配布EXEはリポジトリに含めません。UI翻訳は `i18n.js`、オフラインのヒーロー名は `assets/hero-names.json` にあります。
